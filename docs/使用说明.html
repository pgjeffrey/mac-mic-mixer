Mac Mic Mixer 使用说明

将多个输入合并为一个虚拟麦克风，供会议、语音输入或录音应用使用。无需硬件接收器。

安装与开始使用

  1. 运行适合芯片类型的完整安装包，按照 macOS 提示授权安装，然后重启 Mac。
  2. 从“应用程序”打开 Mac Mic Mixer。点击“添加输入”，从设备列表选择麦克风，可以添加多个。
  3. 点击“开始混音”，在系统提示时允许麦克风权限。分别说话，确认每路电平和总输出电平变化。
  4. 在其他 App 的麦克风设置中选择 Mac Mic Mixer。现在这些 App 将收到合并的声音。

两支蓝牙麦克风需要先通过系统设置配对。软件不限定品牌，但设备必须能够同时向 macOS 提供有效音频输入。

日常操作

  • 每路音量与静音可随时修改。先停止混音，再增加、删除或更换输入设备。
  • 关闭窗口后仍继续收音，可从菜单栏重新打开；选择“退出”会停止音频处理。
  • 可以设置登录 Mac 时启动。已配置且已获得权限的输入可在应用打开时自动开始混音。
  • 断开的输入会显示等待或未连接；软件保留其选择，不会悄悄改用其他麦克风。
  • 虚拟麦克风的左右声道包含相同的混合声音，仅读取单声道的应用也可使用。

检查是否真正接通

在“连接诊断”中选择“发送测试音并验证虚拟麦克风”。这会暂时停止当前混音，发送两种不同测试音并回读虚拟麦克风。其他正在监听此麦克风的 App 也会收到测试音，请避开通话期间操作。

测试音验证成功仅证明软件混音与虚拟设备链路；实际蓝牙输入仍需要分别讲话、同时讲话、断线重连和持续运行验证。

常见问题

  • 设备列表中找不到麦克风：先在系统“声音 → 输入”中检查连接。点击重新检查或等待列表刷新。
  • 显示已连接但没有电平：检查“系统设置 → 隐私与安全性 → 麦克风”中的权限，确认设备未静音。
  • 其他 App 没声音：确认应用正在混音、目标 App 选中了 Mac Mic Mixer，并尝试关闭该 App 的自动音量或强降噪功能。
  • 声音失真或音量过大：降低每路输入或总音量，两路同时说话时也要保留音量余量。
  • 声音卡顿或延迟增长：停止并重新开始混音，重新连接有问题的蓝牙设备；持续增长的诊断计数可帮助定位问题。
  • 虚拟麦克风尚未就绪：仅复制应用不能安装系统音频插件，请重新运行完整安装包并重启 Mac。

升级与卸载

升级前从菜单栏退出应用，再运行安装包。卸载时运行同一交付目录中的 Uninstall 安装包，并按提示重启 Mac。个人选择设置会保留，不会删除其他音频设备或软件。

开发测试版本

当前为 0.1.0 开发版本。未经开发者签名及公证的本机构建可能需要在系统“隐私与安全性”中允许打开。具体设备兼容性和稳定性以实际验收记录为准。
